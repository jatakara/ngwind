# PROJECT NEXUS — Defense

브라우저에서 바로 실행 가능한 의존성 없는 전략 디펜스 게임 MVP입니다.

## 실행
`index.html`을 최신 브라우저로 열면 됩니다. 별도 빌드/서버/계정이 필요하지 않습니다.

## 구현 완료
- 포인터/터치로 포탑 배치, 자원 차감
- 웨이브 적 생성 및 자동 타게팅/발사
- 점수, 보상, 기지 체력, 패배, 재시작
- 외부 패키지나 외부 네트워크 호출 없음

## 개발 로드맵
1. 적 종류, 포탑 업그레이드, 난이도 밸런스
2. 웨이브 보스 및 로그라이크 업그레이드 선택
3. 접근성, 테스트 자동화, 모바일 UX, 저장 기능
4. RL 실험환경과 연계 (게임 플레이와 별도 격리)
5. 퍼블리싱/수익성 검증

## 보안/확장성
초기에는 클라이언트 전용 오프라인 게임. 서버 도입 시 점수 위변조 방지, 인증, 속도 제한, 개인정보 최소 수집이 필수입니다. 프레임별 O(N*M) 타게팅은 적/포탑 수 증가 시 공간 인덱스 도입 검토.
